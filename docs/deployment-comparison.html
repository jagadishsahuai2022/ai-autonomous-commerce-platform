Deployment Strategies

Three approaches ranked by ease and cost

Strategy A: Single VPS + Docker Compose (Recommended)

Best for: Hetzner, Hostinger, DigitalOcean, Vultr

Provision an 8GB VPS with Docker pre-installed

Select Ubuntu 22.04/24.04 with Docker 1-click app. SSH in and verify docker compose version.

Clone repo & configure environment

git clone <repo> → copy .env with DB credentials, JWT secrets. No API keys needed for portfolio demo.

Build and deploy with single command

docker compose -f docker-compose.latest.yml up -d --build — identical to your local setup. Takes ~10–15 min first time.

Configure reverse proxy + SSL

Add Nginx or Caddy as reverse proxy → point domain → auto-SSL via Let's Encrypt. Map yourdomain.com → :3010 (web), api.yourdomain.com → :3002.

Set up 2GB swap (safety net for builds)

fallocate -l 2G /swapfile && mkswap /swapfile && swapon /swapfile — prevents OOM during Next.js builds.

Strategy B: PaaS with Git-Push Deploy (Railway)

Easiest deployment, but highest cost for 10 services

Connect GitHub repo to Railway

Each service becomes a Railway service. Configure Dockerfiles per app. Postgres + Redis from Railway templates.

Replace Kafka with HTTP or Redis pub/sub

Railway doesn't have managed Kafka. Either self-host Kafka as a service (costly) or refactor to use Redis Streams/HTTP.

Push to deploy

git push origin main → auto-build, auto-deploy, auto-SSL. Zero server management.

Strategy C: Hybrid — Hostinger VPS with AI Management

Best middle ground: low cost + managed feel + India datacenter

Get Hostinger KVM 2 (8GB) with Docker template

1-click Docker setup from Hostinger panel. India datacenter for lowest latency. Docker Compose manager in GUI.

Use Kodee AI assistant for server management

Hostinger's MCP-powered AI helps with firewall rules, monitoring, SSL, and troubleshooting directly from the panel.

Upload docker-compose.latest.yml via GUI

Hostinger's Docker Compose Manager provides a visual interface to manage your stack without SSH.

🏆 Final Verdict & Recommendations

🥇 Best Overall Value

Hetzner CX32 — 4 vCPU / 8 GB / 80 GB NVMe for just ~$8–14/mo. Unbeatable price-to-performance. 20 TB included traffic. No contract lock-in. Industry-standard Docker support.

Best if: You're comfortable with SSH + Docker CLI

🥈 Easiest Deployment

Hostinger KVM 2 — $9/mo promo with Docker Compose GUI manager, AI assistant, India datacenter. Free weekly backups. The managed VPS experience closest to PaaS.

Best if: You want GUI management + low latency from India

🥉 Use What You Have

DigitalOcean — You already have an active subscription. The 8GB Droplet at $48/mo works but is 5× more expensive than Hetzner for identical specs. Worth it only if you value the existing familiarity.

Best if: You want to avoid setting up a new provider

💡 Portfolio-Specific Tip

For a portfolio site (low traffic, occasional demo), consider: spin up Hetzner hourly when needed (~€0.012/hr = $0.30/day). Run it during interviews/demos only. Monthly cost: $5–10 actual usage.
